# agent-engineering-lab

个人 Agent 开发学习与实战仓库（P1–P5）。目录设计见 [项目目录结构设计.md](项目目录结构设计.md)。

## 目录地图
- `docs/` 人写的文档（计划、每日记录、笔记、决策、面试）
- `ai/` 给 Agent 看的文件，**仅英文，不上传 GitHub**
- `refs/` 第三方参考源码（仅 `INDEX.md` 入库）
- `labs/` 练习；`projects/` 正式项目；`portfolio/` 对外展示
- `scripts/` 通用脚本

## 分支规则
`main` 为已审核主线；`Claude` / `Codex` 为两个 Agent 的工作分支，经 Pull Request 人工审核后才合并进 `main`。详见 `AGENTS.md`。
